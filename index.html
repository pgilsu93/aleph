경험 상세

01 · 이상탐지 연구

시간 정보를 더하면
탐지가 나아질까

로그 그래프에 시간 정보를 반영한 방법 비교

기존 로그 그래프에 시간 정보를 반영하면 이상탐지 성능을 개선할 수 있을지 살펴봤습니다. 가까운 시간에 발생한 로그 사이의 관계에 가중치를 주는 방법, 짧은 시간에 로그가 몰리는 정도를 반영하는 방법, 일부 연결만 남기는 Top-k 방식 등을 비교했습니다.

기존 방법을 비교 기준으로 두고 BGL, Thunderbird, HDFS에 각 방법을 적용했습니다. 한 데이터셋에서 나온 결과만으로 효과를 판단하지 않도록 데이터별 결과를 나누어 살폈고, 개별 적용과 여러 방법을 결합한 경우도 비교했습니다.

시간 가중치를 적용했을 때는 세 데이터셋 모두에서 F1이 개선됐습니다. 반면 가장 높은 성능을 보인 방법은 달랐습니다. Thunderbird에서는 로그의 발생 집중도를 반영한 방법이, HDFS에서는 Top-k 방식이 가장 좋은 결과를 보였습니다. 여러 방법을 결합한 실험에서는 개별 적용보다 성능이 낮아지는 경우도 있었습니다.

이 결과를 바탕으로 공통으로 개선을 보인 방법과 특정 데이터에서 효과적이었던 방법을 구분했습니다. 개선 요소를 추가하거나 결합할 때에도, 실제 비교 결과를 확인한 뒤 그 효과와 한계를 설명하려고 했습니다.

02 · 웹 시스템 유지보수

화면에서 보이는 현상을
내부 처리 흐름까지 따라가며

운영 웹 시스템의 요청 반영과 오류 원인 추적

웹 시스템 유지보수 업무에서 화면과 처리 로직 수정, SQL을 통한 데이터 조회·처리, 운영 오류 확인을 맡았습니다. 사용자가 접하는 화면의 동작은 내부 로직과 데이터 처리에 연결되어 있었기 때문에, 요청받은 부분을 이해하려면 관련 흐름을 함께 살펴야 했습니다.

사용자 요청을 반영할 때는 화면 구성과 애플리케이션 로직, 필요한 데이터를 조회하는 SQL을 함께 다뤘습니다. 화면에서 무엇이 달라져야 하는지 확인하고, 그 동작에 연결된 처리 과정에서 수정할 지점을 살폈습니다.

운영 중 오류가 발생하면 요청의 처리 흐름과 애플리케이션 로그를 확인하며 원인을 추적했습니다. 화면에서 관찰된 현상을 내부 처리 과정과 연결해 이해하는 데 집중했습니다.

수정 이후에는 변경한 부분과 연결된 기능을 확인하며 영향 범위를 점검했습니다. 요청된 동작을 반영하는 것과 함께, 기존 기능에 어떤 영향을 주는지도 유지보수 업무의 일부로 다뤘습니다.

이 경험을 통해 화면, 서버 로직, 데이터 처리를 오가며 문제를 파악하고, 수정할 지점과 함께 확인해야 할 범위를 판단하는 방식 을 익혔습니다.

03 · 학습과 지식 공유

혼자 아는 것보다
설명할 수 있을 때까지

Java 동아리 수업과 AI 교육과정에서의 학습 지원

대학교 4학년 때 학과에서 Java를 어려워하는 학생들이 많아 Java 동아리가 만들어졌고, 요청을 받아 한 학기 동안 다른 학생과 교대로 수업을 진행했습니다.

수업에서는 제가 알고 있는 내용을 그대로 말하기보다, 처음 배우는 사람이 따라올 수 있도록 개념과 코드의 순서를 나누어 설명하려고 했습니다. 이후 6개월 AI 교육과정에서도 주변 교육생이 어려워하는 내용을 설명하고 코드 오류의 원인을 함께 확인했습니다.

Java 동아리에서는 한 학기 동안 수업을 이어갔고, AI 교육과정은 수료하면서 우수상을 받았습니다. 두 경험을 통해 새로운 내용을 배우는 것과 다른 사람이 이해할 수 있는 형태로 다시 정리하는 과정이 서로 연결되어 있다는 점을 확인했습니다.

이후에도 새로운 기술을 배울 때 원리와 과정을 제 말로 다시 설명할 수 있는지 확인하는 방식을 중요하게 생각합니다.

이런 방식을 좋아합니다.

새로운 것을 배우고 문제를 확인하며 다른 사람과 이야기할 때 자연스럽게 선호하는 방식입니다.

이유가 납득되는 일

무엇을 위한 일인지 이해될 때 더 관심이 갑니다. 배우거나 만드는 일이 제 경험과 어떻게 이어지고, 누구에게 어떤 도움이 되는지 알고 싶습니다.

과정이 보이는 설명

결론에 도달한 과정도 알고 싶습니다. 원리와 순서가 드러나는 설명, 직접 따라가며 확인할 수 있는 예시를 선호합니다.

차분하게 이어지는 대화

상대와 맥락이 잡힌 상태에서 대화를 이어가는 편이 편합니다. 생각을 정리해 말하고, 상대의 이야기도 충분히 이해할 수 있는 자리를 좋아합니다.
