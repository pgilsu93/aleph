01 · 연구 경험

결과가 나온 조건까지 확인합니다.

로그 이상탐지 방법 비교

상황

로그 이상탐지 연구에서 기존 그래프 구조에 시간 정보를 반영하는 방법을 다뤘습니다. 같은 종류의 로그라도 가까운 시간에 연속으로 발생한 경우와 한참 뒤에 발생한 경우에는 차이가 있을 수 있다고 보았습니다.

시간 간격을 반영하거나, 짧은 시간에 로그가 몰리는 정도를 활용하거나, 일부 관계만 남기는 방법이 있었습니다. 각 방법이 어떤 데이터에서 효과적인지 확인할 필요가 있었습니다.

행동
  • 기존 방법을 비교 기준으로 두고 시간 가중치, 로그의 발생 집중도, 그래프 관계를 선택하는 방식을 적용했습니다.
  • 서로 다른 로그 데이터에서 방법별 결과를 비교해, 특정 데이터에서 나타나는 효과와 공통으로 나타나는 개선을 살펴봤습니다.
  • 각 방법을 개별적으로 적용한 결과와 여러 방법을 함께 적용한 결과도 확인했습니다.
결과

시간 가중치를 적용한 방법에서는 여러 데이터셋에 걸쳐 개선을 확인했습니다. 발생 집중도를 반영하거나 일부 관계를 선택하는 방법은 데이터에 따라 효과가 달랐고, 여러 방법의 결합이 항상 더 좋은 결과를 만들지는 않았습니다.

이를 통해 어떤 방법이 좋았는지와 함께, 그 효과가 나타난 조건을 구분해 설명할 수 있었습니다.

02 · 개발 경험

요청을 실제 화면과 기능에 반영합니다.

사용 중인 웹 시스템 유지보수

상황

운영 중인 웹 시스템에서 사용자 요청에 따라 화면과 기능을 수정하고, 발생한 오류를 확인하는 업무를 맡았습니다.

화면에서 보이는 동작은 내부의 조회와 데이터 처리에 연결되어 있었습니다. 요청받은 부분을 변경하면서 관련 기능에 어떤 영향을 주는지도 함께 확인해야 했습니다.

행동
  • 사용자 요청을 바탕으로 화면 구성과 애플리케이션의 처리 로직을 수정했습니다.
  • 화면에 필요한 정보를 조회하고 처리하는 SQL과 데이터 흐름을 다뤘습니다.
  • 운영 중 문제가 발생하면 요청 흐름과 애플리케이션 로그를 살펴보며 원인을 추적했습니다.
  • 수정한 부분과 연결된 기능을 확인해 변경의 영향 범위를 점검했습니다.
결과

사용자 요청을 운영 시스템의 화면과 기능 변경으로 반영했습니다. 화면의 동작과 내부 데이터 처리를 함께 다루며, 수정 내용과 관련 기능의 영향을 확인하는 유지보수 경험을 쌓았습니다.

03 · 방향 설정과 설계

배운 것을 연결해 다음 작업을 구체화합니다.

보안 프로젝트의 방향과 구조 설계

상황

웹 개발과 로그 이상탐지 연구를 경험한 뒤, 네트워크 보안 강의를 들으며 현재의 학습을 앞으로의 직무 준비에 활용할 방법을 고민했습니다.

개발·연구·보안 학습이 한 프로젝트 안에서 각각 어떤 역할을 할 수 있는지 정리할 필요가 있었습니다.

행동
  • 보안 강의의 내용을 활용할 수 있도록 네트워크 흐름에서 이상 징후를 찾는 문제를 프로젝트 방향으로 잡았습니다.
  • 규칙 기반 탐지와 머신러닝·딥러닝 방법을 비교하는 구성을 계획했습니다.
  • 탐지 이후의 과정도 포함해 API, 결과 저장, 조회 화면으로 이어지는 구조를 구상했습니다.
  • 진행 중인 계획에 현재의 학습과 목표를 반영하도록 프로젝트 방향을 조정했습니다.
결과

탐지 대상, 비교할 방법, 결과를 저장하고 조회하는 역할을 구분한 프로젝트 구성을 정리했습니다. 연구 경험은 탐지와 비교 실험에, 웹 개발 경험은 결과를 전달하고 확인하는 기능에 연결했습니다.

여기서 소개하는 경험의 범위는 프로젝트의 방향 설정과 구조 설계입니다.

이런 방식을 좋아합니다.

일을 선택하고, 새로운 것을 배우고, 사람과 대화할 때 중요하게 생각하는 것들입니다.

이유가 납득되는 일

무엇을 위한 일인지 이해될 때 더 관심이 갑니다. 배우거나 만드는 일이 제 경험과 어떻게 이어지고, 누구에게 어떤 도움이 되는지 알고 싶습니다.

과정이 보이는 설명

결론에 도달한 과정도 알고 싶습니다. 원리와 순서가 드러나는 설명, 직접 따라가며 확인할 수 있는 예시를 선호합니다.

차분하게 이어지는 대화

상대와 맥락이 잡힌 상태에서 대화를 이어가는 편이 편합니다. 생각을 정리해 말하고, 상대의 이야기도 충분히 이해할 수 있는 자리를 좋아합니다.

함께 일할 분들께

이 페이지는 함께 일할 분들에게 제가 어떤 경험을 바탕으로 판단하고 행동하는지 소개하기 위해 만들었습니다.

웹 개발과 데이터사이언스 연구를 바탕으로, 문제의 조건과 사용자의 요구를 살피고 경험을 연결해 방향을 찾는 박길수입니다.
